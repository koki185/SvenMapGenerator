===============================================================================
  SVENMAP GENERATOR — ИНСТРУКЦИЯ ПО РАБОТЕ
===============================================================================

Версия: 21 ноября 2026 г.
Проект: детерминированная генерация карт и цепочек карт Sven Co-op кодом,
        без ручного маппинга. Актуальное состояние — campaign.json, planner
        graph_v2, 8 глав, полный QA и слой «Композиция и качество» (P3).

-------------------------------------------------------------------------------
1. ГЛАВНАЯ ТОЧКА ВХОДА
-------------------------------------------------------------------------------

    python generate_campaign.py --build --smoke

Основной рабочий сценарий — кампания из 8 карт (sc_exp_1 … sc_exp_8).
Планировщик graph_v2 используется по умолчанию. Старый planning-путь
доступен как регрессия:

    python generate_campaign.py --planner legacy --build --smoke

Сборка одной главы (удобно при отладке):

    python generate_campaign.py --only sc_exp_1 --planner graph_v2 --build --smoke

Остальные generate_*.py — исторические точки входа этапов 1–6. Они не
рекомендуются для новой работы; подробности в разделе 10.

-------------------------------------------------------------------------------
2. ЧТО НУЖНО ДЛЯ РАБОТЫ
-------------------------------------------------------------------------------

- Python 3.10 (установлен).
- Sven Co-op 5.26 и SDK. Пути ищутся автоматически функцией detect_roots()
  в svenmap/pipeline.py ( SteamLibrary\steamapps\common\Sven Co-op и
  Sven Co-op SDK с компиляторами SC-CSG/BSP/VIS/RAD _x64 ).
- Компиляция не требуется для быстрой генерации .map и метрик.

ВНИМАНИЕ: перед --build и полным QA закройте клиент Sven Co-op — дедикальный
сервер на порту 27021 не может инициализировать Steam, пока открыт клиент.
Первый запуск после закрытия игры иногда даёт «Unable to initialize Steam» —
просто повторите прогон.

3. БЫСТРЫЙ СТАРТ
-------------------------------------------------------------------------------

    cd /d "<папка проекта>"
    python generate_campaign.py --only sc_exp_1 --planner graph_v2
    python generate_campaign.py --only sc_exp_1 --planner graph_v2 --build --smoke

smoke-тест загрузки карты дедикальным сервером.

-------------------------------------------------------------------------------
4. КАМПАНИЯ (campaign.json)
-------------------------------------------------------------------------------

Описание цепочки карт лежит в campaign.json. Поля главы:

    name      имя карты (a-z, 0-9, _), становится именем .map и .cfg
    seed      целое уникальное число — детерминизм планировки
    rooms     число комнат, 4–16
    branches  число боковых веток, 0–4
    theme     тема оформления (сейчас industrial)
    puzzles   цель и механики: collect ИЛИ buttons, плюс secret,
              super_secret, enemies, multi_floor
    pacing    short_6 / standard_8 / dense_10 (необязательно)
    scenes    список имён из scenes.json (необязательно)
    narrative quiet_lab / ventilation / security / boss (необязательно)
    final     true только у последней главы

Проверка до генерации:

    python -m svenmap.campaign_schema campaign.json

Валидатор печатает одну строку на проблему с точным путём и подсказкой,
например:

    chapters[1].seed: seed 101 уже используется в chapters[0]. Выберите другое число.

Машиночитаемая схема для редактора: campaign.schema.json. Закрытый словарь
и few-shot пример для локальной модели: PROMPT.md.

-------------------------------------------------------------------------------
5. КОМПОЗИЦИЯ И КАЧЕСТВО (P3)
-------------------------------------------------------------------------------

Пять файлов данных и модулей отвечают за «интересность» карт:

    pacing.json     три профиля ритма: short_6, standard_8, dense_10
    scenes.json     10 сцен (lobby, server_hall, warehouse, boss_arena, …)
    svenmap/pacing.py              роли комнат и метрики ритма
    svenmap/scenes.py              назначение сцен, текстуры, свет, декор
    svenmap/composition_validator.py  ритм + разнообразие + маршрут (pass/warn)

Сцены реально влияют на игру: подменяют текстуры пола и стен, цвет и яркость
света, а также ставят декор (колонны, ящики, трубы, панели, возвышения).

Превью планировок (реальные L/T/U-формы, связи, цели, дверь, знак выхода,
этажи отдельными панелями, имя сцены в каждой комнате):

    notes\previews\sc_exp_N.svg

Метрики и предупреждения выводятся в отчёте QA:

    notes\campaign_qa_report.md
    notes\campaign_qa_report.json   (details.composition, details.pacing,
                                    details.scenes,
                                    details.composition_validation)

Валидатор композиции — фильтр pass/warn, а не жёсткая ошибка сборки. Метрики
не заменяют прохождение карты человеком.

Подбор альтернативных seed (не меняет campaign.json автоматически):

    python propose_seeds.py --all --count 12 --top 3
    → notes\seed_suggestions.md

-------------------------------------------------------------------------------
5а. АТМОСФЕРА И НАРРАТИВ (P4)
-------------------------------------------------------------------------------

Пресет из narrative.json задаётся полем narrative в campaign.json:

    quiet_lab     тихая лаборатория: гул, спокойное вступление
    ventilation   вентиляция и секреты: шипение воздуха
    security      безопасность: электрический гул, музыка, сирена
    boss          финальная арена: тяжёлая машина, тема сражения

Генератор добавляет:
  - фоновый звук (ambient_generic) в каждой комнате;
  - музыку по зоне (ambient_music) в стартовой комнате;
  - текст вступления (game_text) через 2 секунды после старта;
  - тревогу при открытии двери: красные лампы (изначально выключены),
    звук сирены и предупреждающий текст; если механики нет — тревога
    срабатывает через 10 секунд.

Все звуки проверяются на наличие в svencoop\sound до записи .map.
Сводка — в notes\campaign_qa_report.md (раздел «Атмосфера и нарратив»).

-------------------------------------------------------------------------------
6. КАК ПОПРОБОВАТЬ КАРТУ В ИГРЕ
-------------------------------------------------------------------------------

1. Закройте Sven Co-op, если он открыт: новая .bsp кэшируется при старте.
2. Запустите игру через Steam, включите Developer console в настройках.
3. Нажмите ~ и введите:

       map sc_exp_1

4. Что делать внутри:
   - старт с пистолетом (в HUD будет 250 патронов — лимит игры);
   - найдите 5 ярко светящихся образцов (или 2 генератора в режиме buttons);
   - после сбора откроется дверь в целевую комнату;
   - в целевой комнате видна надпись LEVEL CHANGE (спрайт env_sprite);
   - зайдите в неё — произойдёт переход в следующую главу.

Ручной чек-лист после каждого изменения: карта грузится; игрок не застрял;
цели видны и подсвечиваются; дверь открывается; знак выхода виден; текстуры
целые; комната выглядит естественно.

-------------------------------------------------------------------------------
10. ТЕХНИЧЕСКИЕ НАХОДКИ (НЕ МЕНЯТЬ БЕЗ ПРИЧИНЫ)
-------------------------------------------------------------------------------

1. Нормали граней в .map направлены ВНУТРЬ brush, иначе CSG ругается
   «Illegal Brush», BSP падает с «Exceeded MAX_LEAF_FACES».
2. Проём делается перемычкой над дверью, без булевой резки.
3. Стены, пол и потолок строятся по ЕДИНОЙ клеточной маске комнат + коридоров.
   Bounding box и расчёт стен по отдельным комнатам дают LEAK на L/T/U.
4. У прямых связей portal_a == portal_b (общая клетка) — линии связей в
   превью рисуются между центрами комнат, иначе они нулевой длины.
5. Текстура на trigger_* не отображается в игре: знак выхода — отдельный
   env_sprite sprites/level_change.spr.
6. renderfx 19 (Glow Shell) + rendermode 5 дают неоновый контур предметов.
7. info_player_start ставится на «пол + 48 юнитов» — при 8 игрок застревал.
8. SDL3.dll отсутствует в установке игры: путь добавляется в PATH процесса,
   файлы в папку игры НЕ копируются.
9. CFG пишется и при генерации, и в QA — иначе пистолет появляется только
   на части карт.
