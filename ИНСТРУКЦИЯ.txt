 SVENMAP GENERATOR — ИНСТРУКЦИЯ ПО РАБОТЕ

Версия: 20 ноября 2026 г.
Проект: программная генерация карт для Sven Co-op без ручного маппинга.

-------------------------------------------------------------------------------
1. ЧТО ЭТО И ГДЕ ЛЕЖИТ
-------------------------------------------------------------------------------

Папка проекта:

    C:\Users\Koki185\Documents\Проект по умолчанию

Это НЕ один файл, а модульная программа. Основных точек входа две:

    generate_procedural.py   — генератор карты (основная рабочая программа)
    run_qa.py                — пакетная проверка карт и отчёт

Внутри папки svenmap\ находятся модули генератора (планировщик, геометрия,
текстуры, свет, декор, механика, скрипты, проверки). Подробности — в разделе 8.

-------------------------------------------------------------------------------
3. БЫСТРЫЙ СТАРТ
-------------------------------------------------------------------------------

Откройте командную строку в папке проекта и выполните:

    cd /d "C:\Users\Koki185\Documents\Проект по умолчанию"
    python generate_procedural.py --seed 7 --build --smoke

Что произойдёт:
  1. По seed 7 будет построена планировка (комнаты, коридоры, связи).
  2. Будет создан текстовый исходник .map (полностью кодом).
  3. Сработают проверки: спавн вне геометрии, проходимость, механика.
  4. Сгенерируются текстуры, свет, декор, AngelScript и CFG.
  5. Выполнится компиляция CSG -> BSP -> VIS -> RAD.
  6. Запустится дедикальный сервер и проверится загрузка карты.

Если всё в порядке — в конце появится строка «ANGELSCRIPT: компиляция скрипта успешна»
и карта загружена.

-------------------------------------------------------------------------------
4. ПАРАМЕТРЫ generate_procedural.py
-------------------------------------------------------------------------------

    --seed N        число seed. Одинаковый seed = одинаковая карта.
                    Разный seed = другая планировка. По умолчанию 7.

    --rooms N       сколько комнат в главной цепочке. По умолчанию 6.

    --branches N    сколько боковых веток. По умолчанию 1.

    --build         запустить компиляцию в .bsp.
    --smoke         проверить загрузку карты сервером (нужен --build).
    --no-decor      собрать карту без декора (для сравнения).
    --no-mechanics  не добавлять дверь и генераторы.
    --no-script     не генерировать AngelScript и CFG.

Примеры:

    python generate_procedural.py --seed 12
    python generate_procedural.py --seed 3 --rooms 7 --branches 2
    python generate_procedural.py --seed 7 --build --smoke

Без --build создаётся только .map и SVG-превью — это быстро и безопасно.

6. КАК ПОПРОБОВАТЬ КАРТУ В ИГРЕ
-------------------------------------------------------------------------------

1. Закройте Sven Co-op, если он открыт: новая .bsp кэшируется при старте.
2. Запустите Sven Co-op через Steam.
3. Включите Developer console в настройках, если она выключена.
4. Нажмите ~ и введите:

       map sc_gen_7

5. Что делать внутри:
   - Вы стартуете в комнате spawn.
   - Найдите две панели-генератора (текстура +0BUTTON1, синеватые).
   - Подойдите к каждой и нажмите E. Появятся сообщения о генераторах.
   - После второго нажатия откроется красная дверь перед ареной.
   - Пройдите через неё в финальную комнату — это цель.

Схему с дверью (красное), кнопками (GEN1/GEN2) и маршрутом (зелёное)
смотрите в maps\sc_gen_N_preview.svg.

-------------------------------------------------------------------------------
6а. КОРОТКИЙ РУЧНОЙ ЧЕК-ЛИСТ ПОСЛЕ КАЖДОГО ИЗМЕНЕНИЯ
-------------------------------------------------------------------------------

Автоматический QA доказывает только, что карта собралась и загрузилась.
Следующее обязательно проверяется вручную:

  [ ] карта загружается (нет ошибки при `map sc_gen_N`);
  [ ] игрок двигается с самого старта, не застрял в полу;
  [ ] обе кнопки-генератора видны и нажимаются клавишей E;
  [ ] после двух нажатий дверь открывается;
  [ ] цель (финальная комната) достижима;
  [ ] текстуры целые, кнопка не разорвана на половинки;
  [ ] размеры комнат выглядят естественно для игрока.

-------------------------------------------------------------------------------
7. ПАКЕТНАЯ ПРОВЕРКА (QA)
-------------------------------------------------------------------------------

    python run_qa.py --seeds 1-8

Проверяет каждый seed по 16 пунктам: планирование, проходимость,
расположение спавна, достижимость кнопок, запирание двери, компиляцию
CSG/BSP/VIS/RAD, отсутствие LEAK, наличие скриптов, компиляцию AngelScript
и загрузку карты.

Результат:

    notes\qa_report.md
    notes\qa_report.json

Дополнительные флаги:

    --no-compile   только геометрия и проверки, без BSP
    --no-smoke     без запуска сервера (например, если игра открыта)
    --rooms N      число комнат
    --branches N   число веток

-------------------------------------------------------------------------------
9. ИЗВЕСТНЫЕ ОСОБЕННОСТИ И РЕШЕНИЯ
-------------------------------------------------------------------------------

1. нормали граней в .map направлены ВНУТРЬ brush, а не наружу — иначе
   CSG ругается «Illegal Brush», BSP падает с «Exceeded MAX_LEAF_FACES».
2. Проёмы делаются перемычкой над дверью, без булевой резки.
3. Стены строятся по всем 4 направлениям клетки. Проверка только
   «вправо/вверх» даёт LEAK и падение VIS.
4. Масштаб текстур всегда 1.0. Попытка выровнять тайл по юнитам рвёт
   рисунки (круглая кнопка превращалась в «бабочку»).
5. info_player_start ставится на «пол + 48 юнитов». При смещении 8
   юнитов игрок застревал в полу и не мог двигаться.
6. svends.exe не видит SDL3.dll в установке игры. Обход: добавить
   C:\Program Files (x86)\Steam\bin\cef\cef.win7 в PATH процесса —
   файлы в папку игры НЕ копируются.
7. Smoke-тест использует порт 27021. Пока открыт клиент Sven Co-op,
   дедикальный сервер не может инициализировать Steam — закрывайте
   игру перед --smoke и полным QA.
8. Первый запуск сервера сразу после закрытия игры иногда даёт
   «Unable to initialize Steam» — просто повторите прогон.

-------------------------------------------------------------------------------
9а. КАМПАНИЯ НЕСКОЛЬКИХ КАРТ
-------------------------------------------------------------------------------

Описание цепочки карт лежит в campaign.json. Каждая глава задаёт имя,
seed, число комнат, число веток и признак final. Последняя глава —
финальная арена, остальные получают переход в следующую карту.

    python generate_campaign.py
    python generate_campaign.py --build --smoke

Результат в maps\sc_exp_1.map ... и в svencoop_addon\maps\sc_exp_N.bsp.
Каждая карта получает:
  - четыре info_player_deathmatch для коопа;
  - задачу из поля puzzles: "collect" — собрать 5 образцов
    (item_security + game_counter с health=1..5), иначе две кнопки;
  - прогресс показывается по центру экрана ("Samples: 2/5") и зависит
    от реального состояния задачи, а не от того, какой триггер сработал;
  - при puzzles "secret" добавляется скрытая кнопка, счётчик секретов
    и дверь в бонусную боковую комнату ("Secrets: 1/1");
  - дверь и AngelScript с номером главы;
  - trigger_changelevel в следующую карту (кроме финала);
  - в финале — три волны squadmaker вместо перехода.

Проверка цепочки до генерации: уникальность имён и seed, ровно один
финал. Дальше каждая карта проходит те же проверки, что и одиночная.

-------------------------------------------------------------------------------
9б. ПОЛНЫЙ QA КАМПАНИИ
-------------------------------------------------------------------------------

    python run_campaign_qa.py

Проверяет все главы: переходы, кооп-спавны, доступность комнат,
предметы/кнопки, секреты, отсутствие LEAK, компиляцию, загрузку и
компиляцию AngelScript. Отчёт: notes\campaign_qa_report.md и .json.

Текущая кампания: 10/12/8 комнат, сетка 192 юнита, BSP 0.5-0.94 МБ.
В обычных главах — сбор 5 образцов, 3 засады; в главе 2 — два уровня
секретов (4 скрытые кнопки, 2 бонусные двери); финал — 5 волн босса.

    python generate_blueprint.py --seed 42
    python generate_blueprint.py --seed 1 --count 5
    python generate_blueprint.py --seed 1 --floors 2   # этажи и лестница

Результат в blueprints/*.json и *_spatial.svg. Blueprint включает
формы комнат (rect/L/T/U) и маски клеток. Тесты:
    python -m unittest discover -s tests -v

Полная сборка через новый pipeline (PR-5):

    python generate_v2.py --seed 42 --build --smoke --next sc_exp_2

Геометрия по L/T/U-маскам (PR-6):

    python generate_v3.py --seed 42 --build --smoke

Старый планировщик svenmap/planner.py работает как раньше.

-------------------------------------------------------------------------------
10. ЧЕГО ПРОГРАММА НЕ УМЕЕТ
-------------------------------------------------------------------------------

- Не проверяет реальное прохождение игроком (нажатие кнопок, бой).
- Не проверяет внешний вид в движке — только SVG-схему сверху.
- Не генерирует волн врагов, боссов, секретов, вертикальных переходов.
- Не обеспечивает игровой дизайн и баланс — это пока за человеком.
